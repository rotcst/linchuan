# Linchuan

Linchuan は家庭内 LAN または任意の HTTPS Cloudflare Tunnel で Windows PC とスマートフォンを接続します。Windows ではブラウザーや WebView を使わない C# WPF ネイティブアプリを使い、スマートフォンでは Web インターフェースを使います。オンライン端末、公開・個別チャット、ファイル保存、メディアプレビューを共有できます。

## クイックスタート

1. Windows 10/11 x64 のコンピューターで Releases から **Linchuan.exe** をダウンロードしてダブルクリックします。ターミナルや別途 Node.js をインストールする必要はありません。
2. アプリは組み込みファイルを `%LOCALAPPDATA%\Linchuan\app` に準備し、サービスデータを `%LOCALAPPDATA%\Linchuan\data` に保存します。ウィンドウを閉じるとトレイに隠れて接続を維持します。トレイまたはウィンドウの **Linchuan を終了** は、このインスタンスが起動したサービスだけを停止します。もう一度 EXE を起動すると既存のウィンドウをアクティブにします。
3. 別の Windows コンピューターでも同じ EXE を実行し、最初の接続画面で最初のコンピューターのアドレスと接続コードを入力します。スマートフォンでは右側の接続パネルの QR コードをスキャンするか、LAN/HTTPS アドレスを開いてコードを入力します。Web ページだけで停止中のホストを起動することはできません。
4. Windows ファイアウォールが LAN 接続をブロックする場合は `%LOCALAPPDATA%\Linchuan\app\允许局域网访问.cmd` を実行し、管理者の確認を許可します。TCP 3939 のローカルサブネットだけを許可します。

単一 EXE には .NET ランタイム、Node.js バックエンド、Cloudflare ランタイムが含まれます。初回起動時に管理対象ファイルを展開し、更新してもサービスデータを保持します。ネイティブのセッショントークンは現在の Windows ユーザー用 DPAPI で `%LOCALAPPDATA%\Linchuan\desktop` に保護されます。未署名アプリの警告が表示される場合があるため、Release に掲載された SHA-256 を確認してください。

## バージョンと更新

メインウィンドウ左下とシステムトレイメニューにインストール済みバージョンと **更新を確認** が表示されます。手動確認では、このリポジトリの最新安定 GitHub Release を取得します。新しい版がある場合は公式 Release ページを開き、単一 EXE をダウンロードできます。ネットワーク失敗、最新状態、プレビュー版が最新安定版より新しい状態を区別して表示します。確認中にチャット、ファイル、Tunnel の資格情報をアップロードすることはありません。

Release の SHA-256 を確認し、**Linchuan を終了**してから新しい EXE を実行してください。既存の `data` と `desktop` ディレクトリは保持されます。更新確認がファイルを自動インストール・実行したり、サービスを再起動したりすることはありません。

## ホストと端末の使い方

常時起動し、スリープしない Windows コンピューターをサービスコンピューターにします。別の PC は同じ EXE で接続でき、スマートフォンはサービスコンピューターの Web アドレスを使います。接続先一覧にはホスト専用の `http://127.0.0.1:<実際のポート>`、検出された LAN アドレス、保存済み HTTPS アドレスが含まれます。loopback アドレスはホスト自身でだけ使え、保存された公開 URL が表示されても Tunnel の接続を保証するものではありません。

公開チャットは参加中のすべての端末に送信され、左側の端末一覧から個別チャットを選べます。スマートフォンでは **端末** を開きます。クリップアイコンで任意のファイルを選び、画像アイコンで写真や動画を選択します。PC ではファイルをドラッグ＆ドロップできます。

## インターネットモード

インターネットモードは任意で、Cloudflare Tunnel を使います。設定画面ではマスクされた DNS 編集トークン、所有するホスト名、Cloudflare Zone ID、任意の Wrangler パスを入力します。他のプロジェクトのチェックアウトは参照しません。既存の `data/cloudflare.json` メタデータは設定画面の初期値として使われます。

1. 公式 Cloudflare ドキュメントに従って Wrangler を入手し、`wrangler login` と `wrangler whoami` でアカウントを確認します。
2. EXE から `%LOCALAPPDATA%\Linchuan\app\scripts\配置固定域名.cmd` を実行し、専用サブドメインと Zone ID を入力します。画面に表示された DNS レコードを確認してください。
3. **Linchuan を終了**してから **Linchuan.exe** をもう一度実行します。構成済みの Tunnel は自動的に起動します。`--local` は LAN 専用モードを強制します。

パッケージには固定された Cloudflare ランタイムバイナリが含まれます。ソースビルドでは `node scripts/fetch-runtime.mjs` が公式リリースをダウンロードし、固定 SHA-256 を検証します。Cloudflare Tunnel にルーターのポート転送は不要ですが、アプリと依存サービスは起動している必要があります。

## データ、プライバシー、バックアップ

`%LOCALAPPDATA%\Linchuan\data\linchuan.sqlite` にチャット・端末・ファイルのインデックスを保存し、ファイル本体は `uploads`、生成したプレビューは `previews` に保存します。データは標準で保持され、ディスク全体の暗号化は行いません。端末上でメッセージを非表示にしても、元のファイルや他の端末の履歴は削除されません。

バックアップする前にサービスコンピューターで **Linchuan を終了**し、`data` ディレクトリ全体をバックアップしてください。別のユーザーまたは PC に Tunnel を移す場合、現在の Windows ユーザーに結び付いた DPAPI 資格情報を再設定する必要があります。`data` にはチャット、ファイル、資格情報が含まれるため、公開・送信しないでください。

LAN 通信は HTTP、インターネットモードは設定済みホスト名の HTTPS です。エンドツーエンド暗号化は提供しません。6 桁の接続コードとリクエストレート制限は利便性のための仕組みであり、信頼できるユーザー、ファイアウォール、HTTPS の代わりにはなりません。

ソース/フォルダー起動はプロジェクトまたはパッケージ内の `data` を使い、EXE は上記 AppData の場所を使います。旧 Web ホストから移行する場合は `cloudflare.json` と `tunnel-token.dpapi` を実際の EXE データディレクトリに組で置き、同じ Windows ユーザーのままにしてください。パッケージ化された開発ツールは AppData をリダイレクトする場合があるため、エクスプローラーからアプリと設定を起動して実際の場所を確認してください。既存のチャットデータベースを上書きしないでください。

## ファイル転送とプレビュー

ファイル種類のフィルターや、人為的な単一ファイルサイズ上限はありません。ファイルは 8 MiB チャンクでストリーミングし、一度に最大 20 個まで順番に選択できます。サーバーは 256 MiB 以上のディスク空き容量を残すポリシーを使います。実際の転送可否はディスク、ネットワーク、OS、ブラウザーの機能に依存します。中断したチャンクは一時的なネットワークエラー後に再試行され、ページ更新やサービス再起動後の未完了転送はファイルを選び直してください。

画像は生成された PNG プレビューで表示し、元ファイルは変更しません。Windows では拡大縮小、ドラッグ、左右移動、コピー、端末ごとの削除に対応します。動画は一時キャッシュにダウンロードして Windows のコーデックで再生します。対応しないコーデックでも元ファイルはダウンロードできます。スマートフォンの保存・共有は OS のメニューを使い、Web ページが写真ライブラリへ黙って書き込むことはありません。

## トラブルシューティング

- 接続できない場合は、両方の端末が同じゲストではない Wi-Fi にあり、AP 隔離が無効か確認します。
- 管理者として `允许局域网访问.cmd` を実行し、TCP 3939 とローカルサブネットのファイアウォール規則を作成します。
- VPN や仮想アダプターがある場合は、家庭用ルーターに接続された LAN アドレスを選びます。
- ネイティブのホストウィンドウでインターネット状態を確認します。他の端末が接続するには、ホストが起動中でオンライン、かつスリープしていない必要があります。
- Cloudflare 1033 は正常な Tunnel コネクターがないことを示します。ページは開くのにネイティブクライアントが HTTP 403 やブラウザチャレンジを受ける場合は、専用ホストの `/api/` と `/ws` にブラウザー専用チャレンジ規則が適用されていないか確認してください。ネイティブクライアントは `Linchuan/<version>` として自身を識別しますが、JavaScript チャレンジを完了できません。変更範囲はサービスホストとエンドポイントに限定し、アプリの認証とレート制限を維持してください。

## 開発とチェック

```powershell
npm ci
npm run lint
npm run format:check
npm run typecheck
npm test
npm audit --audit-level=moderate
npm run build
npx playwright install chromium
npm run test:browser
npx tsx scripts/language-check.ts
npx tsx scripts/visual-check.ts
node scripts/fetch-runtime.mjs
npm run package
dotnet build native/Linchuan.Desktop/Linchuan.Desktop.csproj -c Release
dotnet run --project native/Linchuan.Desktop.Tests -c Release
pwsh -NoProfile -ExecutionPolicy Bypass -File scripts/build-desktop.ps1
pwsh -NoProfile -ExecutionPolicy Bypass -File scripts/test-desktop.ps1
```

ソース開発には Node.js 24.14.1 以上と Windows の .NET 10 SDK および PowerShell 7 が必要です。利用者は別途ランタイムをインストールする必要がありません。ホットリロードでは `npm run server:dev` と `npm run dev` を別々に実行します。ブラウザーおよびネイティブテストは隔離した一時データを使い、ネイティブ検証は実際の WPF コントロール、WebSocket のオンライン状態、プライバシー、多重チャンク SHA-256 転送、ギャラリー、4 言語、2 テーマを確認して `qa/native` にスクリーンショットを保存します。

両方のインターフェースは中国語簡体字、英語、韓国語、日本語、丸い国旗メニュー、ライト・チャコールダーク・システムテーマに対応します。チャット本文とユーザーが設定した端末名は翻訳しません。参加時に以前のコンピューターの端末 ID を明示的に選ぶと、個別履歴と非表示状態を維持できます。この ID 取り込み API はリモートおよびブラウザー Origin の要求を拒否します。

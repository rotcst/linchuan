# 邻传

Windows 使用 C# WPF 原生程序，手机使用网页；查看在线设备、公共聊天或私聊、互传任意类型文件。支持家庭局域网及 HTTPS 互联网入口。Windows 界面不使用浏览器或 WebView。

## 谁是服务电脑

选一台经常开机的 Windows 10/11 x64 电脑，下载并双击 **Linchuan.exe**，在它的原生窗口查看连接地址和 6 位连接码。另一台 Windows 电脑也双击同一 EXE，在「连接你的设备」中填写服务电脑地址和连接码；手机打开服务电脑网址。最先打开网页的设备不会自动成为服务电脑，网页也不能启动关闭的服务。

双击后打开原生聊天窗口，不需要终端。关闭窗口会隐藏到系统托盘并保持在线；托盘或窗口中的「退出邻传」会关闭本实例启动的服务。再次双击激活原有窗口。远端无法读取本机连接码。

单 EXE 内置 .NET 运行时、Node.js 服务和通道运行时，首次运行准备程序文件到 `%LOCALAPPDATA%\Linchuan\app`，聊天、文件和通道凭据仍在 `%LOCALAPPDATA%\Linchuan\data`。更新保留原数据。桌面会话和偏好在 `%LOCALAPPDATA%\Linchuan\desktop`，会话凭据用当前用户 DPAPI 加密。程序尚未签名，请核对发布页 SHA-256。

## 版本与更新

主窗口左下方及系统托盘菜单显示当前版本，均提供「检查更新」。点击后查询本仓库最新的正式 GitHub Release；有新版本时可打开官方发布页下载单 EXE。检查失败会显示网络错误，不会把失败当成「已是最新版本」。检查更新不上传聊天、文件或通道凭据。

下载后核对发布页 SHA-256，先选择「退出邻传」，再运行新版 EXE。更新会保留 `data` 和 `desktop`；检查更新不会自动安装、执行下载文件或重启服务。

## 使用

1. 服务电脑双击 **Linchuan.exe**，首次连接填写设备名称；可明确选择本机旧电脑身份，保留原私聊和删除状态。
2. 手机扫描右侧连接信息中的二维码打开网页；另一台 Windows 电脑运行 EXE，在首次连接窗口输入服务电脑的 **192.168…:3939** 地址和连接码。已连接后可在「设备设置 → 切换服务电脑」更换连接目标。
3. 互联网使用先登录 Wrangler，再运行 `%LOCALAPPDATA%\Linchuan\app\scripts\配置固定域名.cmd`，在本地遮罩窗口填写自己的独立子域、Zone ID 和 DNS 编辑 Token。配置成功后退出邻传，重新双击 EXE，自动启用已配置通道。
4. 外出的手机打开 **HTTPS 公网地址**；Windows 原生客户端在连接窗口填写同一 HTTPS 地址和连接码。服务电脑仍需开机、联网且不休眠。
5. 左侧公共聊天室发给所有加入的设备；点击某个设备进入私聊。手机点击「设备」打开列表。
6. 回形针选择任意文件；照片图标选择相册照片和视频，支持多选。电脑还可拖入文件。接收方点击「下载」保存。

## 文件与记录

下文 `data` 指持久数据目录：EXE 使用 `%LOCALAPPDATA%\Linchuan\data`，源码及文件夹包使用自身目录的 `data`。

- 不按文件类型过滤，不设置人为单文件大小上限或总存储上限。8 MiB 分块流式上传，显示进度并可取消；最终能否保存取决于磁盘可用空间、操作系统和浏览器能力。服务电脑保留 256 MiB 磁盘余量。
- 一次最多选择 20 个文件，按顺序上传；各设备之间可同时传输。网络短暂中断会重试当前分块。刷新页面或服务重启后的未完成上传需要重新选择文件。
- 聊天、设备和文件索引保存在 `data/linchuan.sqlite`，文件本体在 `data/uploads`。默认不自动过期，服务重启后保留。发送方和接收方均可删除自己的聊天记录：仅从操作设备的聊天列表中移除，刷新及服务重启后仍保持删除状态，其他设备的记录和下载能力保留。为供其他设备继续使用，服务器原文件仍保留；这不是撤回或释放服务器磁盘的操作。
- 初次显示最新 200 条记录，点击「查看更早的消息」读取历史。私聊历史及文件仅发送方与接收方可访问。
- 浏览器会话保留 30 天并在使用时续期，重启不强制退出。重启后的新连接码显示在本机原生窗口；之前仍有效的设备会话自动重连。
- 备份时先在服务电脑选择「退出邻传」，再备份整个 `data` 文件夹。迁移到另一台电脑时，Cloudflare 通道凭据受原 Windows 用户保护，需要在新电脑重新配置。不要公开或发送整个 data 文件夹，它包含聊天、文件和凭据。
- 局域网用 HTTP，公网用 HTTPS；未实现端到端加密。手机后台或锁屏可能暂停上传，请在传输期间保持网页前台。

## 其他设备打不开

先确认服务电脑的原生窗口已连接，另一台设备使用的是服务电脑的局域网地址，而不是 localhost 或 127.0.0.1。

双击 **允许局域网访问.cmd**，在 Windows 管理员提示中允许操作。只为本机运行时添加 TCP 3939、本地子网范围的入站规则，涵盖 Private/Public，不修改路由器。更换免安装版存放路径后需重新运行一次，使规则匹配新的运行时路径。

检查手机是否在访客 Wi-Fi、路由器是否开启 AP 隔离。有虚拟网卡或 VPN 时，在右侧连接入口中选择家用路由器的地址。互联网异常时查看本机窗口的通道状态，以及启动窗口中的错误提示。

连接入口列表包括本机 `http://127.0.0.1:3939`、检测到的局域网地址及已保存的 HTTPS 公网域名。本机地址仅服务电脑自己可用。公网入口出现不代表通道已连通，应同时检查「互联网通道已连接」状态。

从旧网页版迁移时，源码或文件夹包的 `data` 与单 EXE 的 AppData 数据目录不同。公网元数据 `cloudflare.json` 与 `tunnel-token.dpapi` 必须成对保存在单 EXE 的实际数据目录，并属于同一 Windows 用户。某些打包开发工具会重定向 AppData 文件访问；在资源管理器中运行程序和配置窗口，并确认实际数据目录，避免仅凭开发工具里的文件存在判断迁移成功。不要覆盖已有聊天数据库。

Cloudflare 1033 表示域名没有可用的通道连接，需确认服务电脑及 cloudflared 正在运行。如果网页能打开，但原生客户端收到 403 或浏览器挑战页，应检查该子域 `/api/` 和 `/ws` 是否受到浏览器专用挑战规则影响；原生请求会声明正常的 `Linchuan/<version>` User-Agent，空 User-Agent 的挑战规则可以保留。原生客户端无法执行这类 JavaScript 验证。调整应限定到自己的服务子域和接口，保留应用鉴权、频率限制及其他站点的安全策略。

## 开发与检查

需要 Node.js 24.14.1 或更新版本；免安装版已内置运行时。前端 React + TypeScript + Vite，后端 Express + WebSocket + SQLite。源代码位于 src/server，测试位于 test。

```powershell
npm ci
npm run lint
npm run format:check
npm run typecheck
npm test
npm audit --audit-level=moderate
npm run build
npx playwright install chromium
npm run test:browser
npx tsx scripts/language-check.ts
npx tsx scripts/visual-check.ts
node scripts/fetch-runtime.mjs
npm run package
dotnet build native/Linchuan.Desktop/Linchuan.Desktop.csproj -c Release
dotnet run --project native/Linchuan.Desktop.Tests -c Release
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-desktop.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/test-desktop.ps1
```

浏览器测试需要 Playwright Chromium：`npx playwright install chromium`。测试启动独立临时服务，不触碰真实用户数据。

原生源码在 `native/Linchuan.Desktop`，编译需要 Windows 和 .NET 10 SDK，用户无需另装运行时。开发手机页面时分别运行 `npm run server:dev` 和 `npm run dev`。原生验证使用独立临时服务，真实操作 WPF 控件并生成四语深浅截图到 `qa/native`。

两端均支持简体中文、英文、韩语和日语。圆形国旗菜单显示语言原生名称，主动选择后记住偏好。用户设备名、聊天原文不会被翻译。EXE 参数 `--local` 强制仅局域网；`--server https://你的地址` 可直接作为指定服务的桌面客户端。

## 图片与视频预览

PNG、JPEG、GIF、WebP、AVIF 在聊天中显示缩略图。点击后查看原图，可用滚轮缩放、放大后拖动，点击左右箭头或按键盘左右键切换同一聊天已加载的图片；手机支持双指缩放和横向滑动。预览原图时保留浏览器右键或长按菜单，也提供「下载原图」。缩略图由本机生成并存入 data/previews，原文件不修改；预览继承同样的公开/私聊访问权限。HEIC、特殊图像格式或损坏图片无法预览时，仍可下载原文件。

MP4、MOV、WebM 提供页内播放器，不自动播放，支持浏览器按范围读取和拖动进度。能否播放还取决于设备支持的编码格式，无法解码时可下载原视频。预览处理有像素和并发保护，不影响原文件传输大小。

Windows 原生端使用同样权限的 PNG 缩略图，支持滚轮缩放、拖动、左右切换和右键另存为。视频先流式下载到临时缓存再由系统解码播放，关闭预览删除缓存；编码不兼容时仍可下载原文件。下载仅在成功后替换目标文件。主窗口操作栏与窗口控制一体显示，应用内对话框和预览窗口的标题栏使用相同主题令牌。首次从旧版升级前先退出旧服务，数据目录保持不变。

手机媒体卡片只显示「保存」及删除按钮，避免重复的下载入口；普通文件和电脑端显示「下载」。支持文件分享的 HTTPS 浏览器可准备原文件，再由用户点击系统菜单选择保存；不支持的浏览器、局域网 HTTP 或较大媒体会提供打开原图/视频和下载入口。图片可在原图页面长按保存；视频通常需要浏览器或系统分享菜单中的「存储视频」，具体选项由手机系统提供，网页不能静默写入相册。为了避免手机耗尽内存，系统分享准备仅用于 64 MiB 以内媒体，这不限制文件上传、下载或原视频入口。

## 外观与设计令牌

右上角「外观主题」可选择跟随系统、浅色、深色。偏好只在当前浏览器保存，同一地址的标签页同步，不会改变其他设备的外观、身份或聊天记录。默认跟随系统，手动选择后刷新仍保留。

浅色采用暖白与中性灰；深色采用炭灰与蓝灰层次；翡翠绿只用于操作、选中和联机状态。`src/tokens.css` 是设计令牌来源，分为原始值、语义颜色及组件令牌，组件样式只引用语义或组件变量。字体、间距、圆角和动效使用同一套尺度。

公网仅启用互联网启动入口时开放；六位连接码及请求频率限制不等于绝对安全。不要把连接码发给陌生人。data 中的聊天、照片和文件未做磁盘级加密；开源只发布源码，必须排除整个 data、.env 和凭据。Cloudflare 通道无需路由器端口转发，仍需要保持应用及依赖更新。

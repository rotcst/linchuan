# 邻传

电脑和手机在浏览器中查看在线设备、公共聊天或私聊、互传任意类型文件。支持家庭局域网及 HTTPS 互联网入口。

[English](README.md) · [Windows 下载](https://github.com/rotcst/linchuan/releases) · [安全说明](SECURITY.md) · [设计系统](design/设计说明.md)

## 谁是服务电脑

选一台经常开机的 Windows 10/11 x64 电脑，下载并双击 **Linchuan.exe**，它就是服务电脑。另一台电脑和手机只打开它提供的网址，不需要运行程序。最先打开网页的设备不会自动成为服务电脑；关闭的服务也不能通过网页启动。

双击启动后服务在后台运行，直接打开网页，不需要保持终端打开。再次双击会打开已有服务，不重复启动。本机页面显示 6 位连接码和「停止后台服务」按钮；局域网或互联网远端无法读取这个连接码。

EXE 已内置 Node.js 和通道运行时，首次启动将程序文件准备到 `%LOCALAPPDATA%\Linchuan\app`，聊天、文件和凭据放在独立的 `%LOCALAPPDATA%\Linchuan\data`。这是单文件分发、自动解包的启动程序；关闭网页后后台服务仍继续运行。更新 EXE 保留数据目录。程序尚未进行代码签名，Windows 可能提示未知发布者，请核对发布页的 SHA-256。

## 使用

1. 服务电脑双击 **Linchuan.exe**。网页显示本机连接码。填写名称，点击「本机使用此码」，进入聊天室。文件夹免安装包也保留 VBS/CMD 启动入口。
2. 手机连接家庭 Wi-Fi，扫描网页「添加设备」里的二维码；另一台电脑打开服务电脑的 **192.168…:3939** 地址。输入同一连接码加入。
3. 互联网使用先登录 Wrangler，再运行 `%LOCALAPPDATA%\Linchuan\app\scripts\配置固定域名.cmd`，在本地遮罩窗口填写自己的独立子域、Zone ID 和 DNS 编辑 Token。配置成功后在网页停止当前服务，重新双击 EXE，自动启用已配置通道。文件夹包在自己的 `scripts` 目录配置，再使用 **启动互联网模式.vbs**。
4. 外出的手机或电脑打开配置窗口中设置的 **HTTPS 公网地址**，输入连接码加入。Cloudflare 通道负责公网连接，服务电脑仍需开机、联网且不休眠。
5. 左侧公共聊天室发给所有加入的设备；点击某个设备进入私聊。手机点击「设备」打开列表。
6. 回形针选择任意文件；照片图标选择相册照片和视频，支持多选。电脑还可拖入文件。接收方点击「下载」保存。

## 文件与记录

下文 `data` 指持久数据目录：EXE 使用 `%LOCALAPPDATA%\Linchuan\data`，源码及文件夹包使用自身目录的 `data`。

- 不按文件类型过滤，不设置人为单文件大小上限或总存储上限。8 MiB 分块流式上传，显示进度并可取消；最终能否保存取决于磁盘可用空间、操作系统和浏览器能力。服务电脑保留 256 MiB 磁盘余量。
- 一次最多选择 20 个文件，按顺序上传；各设备之间可同时传输。网络短暂中断会重试当前分块。刷新页面或服务重启后的未完成上传需要重新选择文件。
- 聊天、设备和文件索引保存在 `data/linchuan.sqlite`，文件本体在 `data/uploads`。默认不自动过期，服务重启后保留。发送方和接收方均可删除自己的聊天记录：仅从操作设备的聊天列表中移除，刷新及服务重启后仍保持删除状态，其他设备的记录和下载能力保留。为供其他设备继续使用，服务器原文件仍保留；这不是撤回或释放服务器磁盘的操作。
- 初次显示最新 200 条记录，点击「查看更早的消息」读取历史。私聊历史及文件仅发送方与接收方可访问。
- 浏览器会话保留 30 天并在使用时续期，重启不强制退出。重启后的新连接码显示在本机页面；之前仍有效的设备会话自动重连。
- 备份时先在本机页面停止服务，再备份整个 `data` 文件夹。迁移到另一台电脑时，Cloudflare 通道凭据受原 Windows 用户保护，需要在新电脑重新配置。不要公开或发送整个 data 文件夹，它包含聊天、文件和凭据。
- 局域网用 HTTP，公网用 HTTPS；未实现端到端加密。手机后台或锁屏可能暂停上传，请在传输期间保持网页前台。

## 其他设备打不开

先确认本机网页可用，另一台设备使用的是服务电脑的局域网地址，而不是 localhost 或 127.0.0.1。

双击 **允许局域网访问.cmd**，在 Windows 管理员提示中允许操作。只为本机运行时添加 TCP 3939、本地子网范围的入站规则，涵盖 Private/Public，不修改路由器。更换免安装版存放路径后需重新运行一次，使规则匹配新的运行时路径。

检查手机是否在访客 Wi-Fi、路由器是否开启 AP 隔离。有虚拟网卡或 VPN 时，在添加设备中选择家用路由器的地址。互联网异常时查看本机页面的通道状态，以及启动窗口中的错误提示。

## 开发与检查

需要 Node.js 24.14.1 或更新版本；免安装版已内置运行时。前端 React + TypeScript + Vite，后端 Express + WebSocket + SQLite。源代码位于 src/server，测试位于 test。

```powershell
npm ci
npm run lint
npm run format:check
npm run typecheck
npm test
npm audit --audit-level=moderate
npm run build
npx playwright install chromium
npm run test:browser
npx tsx scripts/language-check.ts
npx tsx scripts/visual-check.ts
node scripts/fetch-runtime.mjs
npm run package
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-launcher.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/test-launcher.ps1
```

浏览器测试需要 Playwright Chromium：`npx playwright install chromium`。测试启动独立临时服务，不触碰真实用户数据。

开发热更新分别运行 `npm run server:dev` 和 `npm run dev`。可选环境变量 PORT（默认 3939）、JOIN_CODE（自定义 6 位连接码）、DATA_DIR（持久数据目录）、INTERNET=1（启用已配置通道）。`启动邻传.ps1 -Local` 强制仅局域网模式。

网页支持简体中文、英文、韩语和日语。圆形国旗菜单显示语言原生名称，初始跟随浏览器语言，主动选择后记住偏好。用户填写的设备名、聊天原文不会被翻译。EXE 参数 `--local` 强制仅局域网，`--noBrowser` 仅后台启动。

## 图片与视频预览

PNG、JPEG、GIF、WebP、AVIF 在聊天中显示缩略图。点击后查看原图，可用滚轮缩放、放大后拖动，点击左右箭头或按键盘左右键切换同一聊天已加载的图片；手机支持双指缩放和横向滑动。预览原图时保留浏览器右键或长按菜单，也提供「下载原图」。缩略图由本机生成并存入 data/previews，原文件不修改；预览继承同样的公开/私聊访问权限。HEIC、特殊图像格式或损坏图片无法预览时，仍可下载原文件。

MP4、MOV、WebM 提供页内播放器，不自动播放，支持浏览器按范围读取和拖动进度。能否播放还取决于设备支持的编码格式，无法解码时可下载原视频。预览处理有像素和并发保护，不影响原文件传输大小。

手机媒体卡片只显示「保存」及删除按钮，避免重复的下载入口；普通文件和电脑端显示「下载」。支持文件分享的 HTTPS 浏览器可准备原文件，再由用户点击系统菜单选择保存；不支持的浏览器、局域网 HTTP 或较大媒体会提供打开原图/视频和下载入口。图片可在原图页面长按保存；视频通常需要浏览器或系统分享菜单中的「存储视频」，具体选项由手机系统提供，网页不能静默写入相册。为了避免手机耗尽内存，系统分享准备仅用于 64 MiB 以内媒体，这不限制文件上传、下载或原视频入口。

## 外观与设计令牌

右上角「外观主题」可选择跟随系统、浅色、深色。偏好只在当前浏览器保存，同一地址的标签页同步，不会改变其他设备的外观、身份或聊天记录。默认跟随系统，手动选择后刷新仍保留。

浅色采用暖白与中性灰；深色采用炭灰与蓝灰层次；翡翠绿只用于操作、选中和联机状态。`src/tokens.css` 是设计令牌来源，分为原始值、语义颜色及组件令牌，组件样式只引用语义或组件变量。字体、间距、圆角和动效使用同一套尺度。

公网仅启用互联网启动入口时开放；六位连接码及请求频率限制不等于绝对安全。不要把连接码发给陌生人。data 中的聊天、照片和文件未做磁盘级加密；开源只发布源码，必须排除整个 data、.env 和凭据。Cloudflare 通道无需路由器端口转发，仍需要保持应用及依赖更新。

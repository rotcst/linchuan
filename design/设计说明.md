# 邻传 · 精密工作台视觉系统

用户已选定并确认的最终方向：暖白浅色、炭灰深色、翡翠绿强调色。有效概念图是 `workbench-light.png`、`workbench-charcoal.png` 和 `workbench-mobile-final.png`，由内置 imagegen 生成。早期绿色深色方案已被用户替换。

## 令牌与组件

`src/tokens.css` 是唯一视觉令牌来源：原始颜色/字体/间距 → 语义颜色 → 组件别名。`styles.css` 通过变量使用令牌，不直接硬编码颜色。`data-theme` 只切换语义层，组件使用同一套结构、排版和状态规则。

| 侧栏           | #F6F5F0 | #171B22 |

字体采用 Segoe UI / Microsoft YaHei / PingFang SC；韩语和日语使用对应系统字体后备。连接码、文件大小和时间用 Cascadia Code / SFMono-Regular / Consolas 等宽字体。桌面正文 14px，消息 15px，辅助文字 11–12px，标签 13px，标题 20px，品牌 22px。手机正文 15px、消息 16px，并保留 44px 触控目标。4px 间距尺度，5/7/10px 几何圆角，图标 1.7px 描边。主题切换不使用全屏过渡动画；尊重减少动态效果偏好。

## 布局和功能

桌面为边到边工作台：56px 顶栏、232px 设备导航、可伸缩聊天画布、304px 连接检查栏。选中设备使用短竖线与低饱和底色，主操作和在线状态使用强调色。连接码、原生二维码白底、地址选择、后台状态和停止入口保持真实功能。

小于 1180px 收起连接检查栏，添加设备仍能打开完整面板。手机收起两侧面板，设备以抽屉打开；输入区固定在聊天区域底部，兼容安全区域。加入页、设备设置、错误、上传进度、保存说明和原图查看器使用同一套令牌。

文件卡片将预览、名称、大小和操作放在同一边框内。桌面和普通文件显示“下载 + 删除”；手机图片/视频仅显示“保存 + 删除”，没有重复下载按钮。文字复制和删除并排收在气泡右下角同一操作区。删除仅移除本设备记录，不影响另一设备记录和文件。

外观选项：跟随系统、浅色、深色。默认跟随系统；手动选择在当前浏览器持久保存，同源标签页同步。入口同源脚本在 React 加载前设置主题，避免暗色首屏闪白，现有 CSP 不放宽。

## 实现比对范围

| 比对点     | 实际实现与验证                                                                                |
| ---------- | --------------------------------------------------------------------------------------------- |
| 工作台结构 | 边到边布局、顶栏及三列细分隔线；1440×732 / 1536×1024 桌面和 390×844 手机实页截图比对。                   |
| 色彩层次   | 暖白/炭灰与蓝灰层次，绿色只用于强调和联机状态；双主题不改变组件结构。                         |
| 信息排版   | 字号层级、等宽数字、紧凑侧栏；输入占位符单行垂直居中，几何偏差不超过 1px，多行自动增高。      |
| 文件操作   | 图片预览、名称/大小、保存或下载和删除整合在一张卡片；手机媒体只有一个保存入口。               |
| 聊天操作   | 复制和删除在气泡内部右下角并排，发送和接收使用同一布局。                            |
| 连接检查栏 | 连接码与复制按钮同排、144px 白底二维码、地址选择及固定存储说明，后台状态真实显示。            |
| 手机适配   | 抽屉设备导航、底部输入框、安全区域；圆形国旗及完整语言菜单在 360/390/430px 无裁切或横向溢出。 |

概念中的风景照片和示例消息仅用于表达组件外观，不植入真实用户聊天室；测试使用独立临时目录和 `demo-coast.png` 示例素材。图库按需加载，预览保留浏览器原生右键及长按菜单。

主要截图尺寸为 1440×732、1536×1024 和 390×844，另检查 360/430px 菜单布局。允许的差异是系统字体、真实消息内容和时间、设备在线状态、动态连接码/地址，以及空输入时发送按钮的禁用状态。连接码复制/输入保持六个数字，二维码保持纯白扫描底色。支持四种语言后标签长度随语言变化，菜单保留原生语言名称。这些功能差异不以静态概念图覆盖。

所有下拉选择器（语言、外观主题、连接入口、设备类型）共用 `SelectMenu`，共享触发器、菜单背景、边框、圆角、间距、选中项与悬停状态令牌。支持方向键、Enter 和 Esc；嵌套菜单按 Esc 只关闭当前菜单。输入框聚焦仅改变原有边框颜色，不添加外围 outline 或 box-shadow；按钮键盘焦点使用内侧提示。
